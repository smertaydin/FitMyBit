# FitMyBit

Google Health verilerine her sabah günlük, pazartesileri haftalık yorum yapan küçük bir PWA.

- Ön yüz: bu repo (GitHub Pages) — `index.html`, `sw.js`, `manifest.webmanifest`
- Arka uç: Supabase (Together projesi) — `gh_*` tabloları, `gh-oauth-callback`, `gh-sync`, `gh-api` edge function'ları
- Yorumlar: Claude zamanlanmış görevi `gh_daily` verisini okuyup `gh_insights` tablosuna yazar

Önizleme: `index.html?demo`
